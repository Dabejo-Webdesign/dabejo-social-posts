# dabejo-social-posts

Bilder für den Instagram-Kanal [@dabejo_com](https://www.instagram.com/dabejo_com/) von Dabejo, Webdesign aus Emsdetten.

Dieses Repo ist nur Ablage: Metricool holt sich die Bilder hier über ihre öffentliche Adresse und veröffentlicht sie zum geplanten Termin.

## Aufbau

```
2026-KW43/
  2026-10-22-a-google-test.jpg     Datum-Reihenfolge-Thema.jpg
  2026-10-22-c-neffe-1.jpg … -5    Karussell: eine Datei pro Bild
  captions.json                    Bildunterschrift je Datei
```

Ein Ordner pro Kalenderwoche. Bilder sind 1080 × 1350 (Instagram 4:5), Stories 1080 × 1920.

Öffentliche Adresse eines Bildes:
`https://raw.githubusercontent.com/Dabejo-Webdesign/dabejo-social-posts/main/<Ordner>/<Datei>`
